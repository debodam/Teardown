Your API key is stored only in your browser and never leaves your device except to communicate directly with Anthropic. This extension has no backend server and never sees, collects, or stores your key. You are responsible for keeping your own key secure.

Remove your API key?
Removing your key will reset Teardown. You'll need to enter a new API key before using it again.
