Teardown — Privacy Policy

Last updated: September 2026

Teardown is a Chrome extension that helps you practice product sense on any product or company page. This page explains what data the extension handles and how.

What Teardown does

When you click the extension on a page, it reads that page's visible text, title, and meta description to determine if it's a product or company page, then generates practice questions and analysis based on that content.

Your API key

Teardown requires your own Claude API key from Anthropic (bring-your-own-key). Your key is:

  • Stored only in your browser's local extension storage, never synced or sent anywhere else
  • Used only to send requests directly from your browser to Anthropic's API
  • Never visible to, collected by, or stored by the developer of this extension

There is no backend server operated by this extension. Nothing you enter is ever transmitted to any server other than Anthropic's own API, using your own key.

Page content

When you use Teardown, the visible text, title, and meta description of the page you're on is sent directly to Anthropic's API (using your key) to generate the analysis. This content is not stored anywhere beyond that single request, not by this extension, not by the developer.

What we don't do

  • No analytics or tracking
  • No browsing history collection
  • No advertising or ad tracking
  • No data sold or shared with third parties
  • No account creation or sign-in required

Third parties

The only third party this extension communicates with is Anthropic, to process your requests using your own API key, subject to Anthropic's own terms and privacy policy.

Your responsibility

You are responsible for keeping your own API key secure, the same as with any bring-your-own-key tool. This extension is provided as-is, with no warranty.
